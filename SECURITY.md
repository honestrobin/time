# Security policy

Please report vulnerabilities privately to **security@honestrobin.com**. Do not open a public issue. We will acknowledge your report within three working days and keep you updated until it is resolved.

Please include steps to reproduce, the affected version or commit, and the impact you expect. We will credit reporters in the release notes unless you prefer otherwise.

## Supported versions

Security fixes go into the latest minor release. Self-hosters should stay on the latest release; see `docs/self-host.md` for upgrade instructions.

## Scope

The application, the Docker image, the browser extension and the published API are in scope. Findings on Honest Robin Cloud infrastructure are also welcome at the same address.
